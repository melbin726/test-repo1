# Getting Started - Your Java Backend Development Journey 🚀

Welcome to the most comprehensive Java backend learning resource! This guide will help you start your journey from complete beginner to professional backend developer.

## 🎯 Quick Start Guide

### Prerequisites
- **Java 17 or higher** - [Download here](https://adoptium.net/)
- **Maven 3.6+** - [Download here](https://maven.apache.org/download.cgi)
- **IDE** - [IntelliJ IDEA](https://www.jetbrains.com/idea/) or [VS Code](https://code.visualstudio.com/)

### Verify Your Setup
```bash
java --version
mvn --version
```

## 📚 Learning Path

### Phase 1: Java Fundamentals (Week 1-2)
**Start here:** [Chapter 1: Java Basics](docs/01-java-basics/README.md)

**What you'll build:**
- Personal information program
- Calculator application
- Grade management system

**Key concepts:**
- Variables, data types, operators
- Control structures (if-else, loops)
- Methods and functions
- User input handling

**Hands-on practice:**
```bash
cd examples/java-basics
mvn compile
mvn exec:java -Dexec.mainClass="com.example.HelloWorld"
```

### Phase 2: Object-Oriented Programming (Week 3-4)
**Continue with:** [Chapter 2: OOP](docs/02-oop/README.md)

**What you'll build:**
- Banking system simulation
- Animal inheritance hierarchy
- Person management system

**Key concepts:**
- Classes and objects
- Inheritance and polymorphism
- Encapsulation and abstraction
- Professional code organization

**Hands-on practice:**
```bash
cd examples/oop
mvn compile
mvn exec:java -Dexec.mainClass="com.example.basic.BasicOOPDemo"
mvn exec:java -Dexec.mainClass="com.example.inheritance.InheritanceDemo"
```

### Phase 3: Your First REST API (Week 5-6)
**Build something amazing:** [Todo API Project](projects/01-todo-api/README.md)

**What you'll build:**
- Complete REST API with Spring Boot
- Database integration with JPA/Hibernate
- Beautiful web frontend
- Professional backend application

**Key concepts:**
- Spring Boot framework
- REST API design
- Database operations
- Frontend-backend integration

**Run your API:**
```bash
cd projects/01-todo-api
mvn spring-boot:run
# Open http://localhost:8080
```
